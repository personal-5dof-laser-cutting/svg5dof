# SVG5DOF

SVG5DOF is an open format for slanted laser cutting (5DOF / 5-axis laser cutting). It extends common conventions for laser cutting SVGs with the ability to encode slanted cuts as pairs of lines in a fully SVG-compliant manner. This repository contains the format specification and example files.
